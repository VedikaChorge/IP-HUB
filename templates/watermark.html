Invisible Watermark & Image Trace

Embed cryptographic identifiers into pixel data using Least Significant Bit (LSB) steganography, and trace suspected copies back to the original registry.

🔬 How Least Significant Bit (LSB) Steganography Operates: Every pixel in an image has color channels (Red, Green, Blue) with values from 0 to 255 (8 bits per channel). The Least Significant Bit (bit 0) represents the tiniest fraction of light intensity (1/256th). Modifying this single bit alters the pixel by an amount completely invisible to human vision. Our algorithm replaces the LSBs of consecutive pixels with the binary encoding of the Evidence ID.

⚠️ Realistic Forensic Limitations: LSB watermarks require lossless storage (PNG format). If an image is converted to lossy JPEG (which uses discrete cosine transform quantization), cropped, resized, or heavily color-filtered, the LSB bit patterns will be altered, preventing automated extraction. This prototype demonstrates steganographic principles for student and research evaluation.
